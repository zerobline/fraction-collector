# Contributing

Contributions are welcome, especially **measured compatibility data**, CAD improvements, and print/test evidence.

When filing a bug or improvement issue include:
- Rack manufacturer, part number and **measured center-to-center pitch** (best: first-to-last centers ÷ 9).
- Tube outside diameter, minimum measured inside diameter and actual lip geometry.
- FreeCAD version and what parameters you changed.
- Fabrication process, material, tolerances and whether the part fits all ten tubes.
- Test liquid, move/indexing method, splash, hold-up volume, carryover and cleaning experience.

If you propose geometry changes, provide an editable FreeCAD source, a drawing derived from the same geometry, and a brief explanation of how you verified the change. Keep parts links descriptive and independent of any specialized end application.

Please do not upload copyrighted supplier photographs or confidential test information without rights. Use GitHub Issues for discussion and a pull request for documentation or CAD updates.
